## 执行摘要

面向 A 股个人投资者的**规则型缠论策略监控**能力。系统自动扫描用户自选股，基于已收盘的日线与 30 分钟 K 线，按固定、可测试的主流缠论规则计算完整结构（K 线包含 → 分型 → 笔 → 线段 → 中枢 → 背驰 → 一、二、三类买卖点），并将正式确认的信号标注在自选股列表和个股 K 线图上。

**核心定位**：

- 不是自动交易，不替代用户判断，**减少用户手工盯盘的工作量与遗漏**；
- 所有信号均为**收盘确认、不重绘**的正式信号，宁可晚一点，不可误导；
- 第一版**仅页面展示**（自选股信号徽标 + K 线结构图层 + 信号历史），不做任何主动推送；
- 界面与文案必须体现「规则参考信号，不构成投资建议」。

与通达信缠论插件相比，差异化在于：信号与个人投研知识库（模块一）、行情展示（模块二）深度打通，可一键从信号进入 AI 深度分析。

## 问题陈述

**现状痛点**：

- 散户每天需要逐一打开自选股 K 线，肉眼判断是否出现缠论结构变化和买卖点，耗时且极易遗漏；
- 通达信缠论插件与个人分析日志完全割裂，且公式自定义门槛高；
- 盘中人工盯 30 分钟级别走势几乎不可行，错过确认时机是常态。

**解决方案**：将主流缠论规则固化为确定性算法引擎，每个交易日收盘后与每个 30 分钟 K 线收盘后自动计算全部启用监控的自选股，把「该看哪只股」这件事交给系统。

**业务影响**：

- 用户每日盯盘时间显著下降（从逐一看图到只看信号徽标）；
- 信号可回放、可验证，建立用户对系统算法的信任；
- 与 AI 个股分析联动，形成「规则信号 → 深度分析 → 决策」的完整闭环。

| 指标 | 目标值 | 测量方式 |
|------|--------|----------|
| 算法分层验收通过率 | 黄金样本集上合并/分型/笔/线段/中枢/背驰/买卖点各层与主流实现一致率 ≥95% | 单元测试 + 人工对照报告 |

| 信号接口响应 | ≤500ms（命中缓存） | API 监控 |

## 缠论算法口径（固定规则基线）

> 本章节是本 PRD 的核心。缠论存在流派差异，为保证可开发与可验收，以下规则为**系统唯一口径**，采用主流客观化实现。算法升级必须递增 `algo_version`，且不允许修改已确认的历史信号。

### 第 0 层：输入数据

- 日线：来自模块二 `t_stock_daily_quote`（前复权）
- 30 分钟线：由**本地原始分钟数据聚合**（见「数据模型」），统一午休、集合竞价处理与前复权口径
- 只使用**已收盘** K 线；未收盘 K 线不参与任何结构计算
- 最少数据要求：日线 ≥60 根、30 分钟线 ≥120 根，不足则该股票该周期标记为「数据不足」

### 第 1 层：K 线包含关系处理

- 判定方向：以上一根已合并 K 线相对再前一根的高低点关系确定当前为上升或下降处理方向
- 上升方向处理包含：取两根 K 线的最高高点、最高低点
- 下降方向处理包含：取两根 K 线的最低高点、最低低点
- 合并后的 K 线保留原始交易日/时间映射，用于信号定位

### 第 2 层：顶底分型

- 顶分型：相邻 3 根合并 K 线，中间一根高点最高且低点最高
- 底分型：相邻 3 根合并 K 线，中间一根低点最低且高点最低
- 相邻同向分型处理：取极值更高（顶）/更低（底）者，另一个作废

### 第 3 层：笔

- 顶底分型必须交替出现才能成笔
- 成笔条件（采用通用标准）：两分型之间（不含分型共用部分）至少存在 1 根独立合并 K 线，即一笔至少包含 5 根合并 K 线
- 向上笔：底分型 → 顶分型；向下笔：顶分型 → 底分型
- 最新一笔在未被后续分型确认前视为**未完成笔**，只用于结构展示，不产生任何信号

### 第 4 层：线段

- 一线段至少由 3 笔构成
- 线段终结采用**特征序列法**：
  - 向上线段：以所有向下笔构成特征序列，做包含处理后出现顶分型 → 线段终结
  - 向下线段：以所有向上笔构成特征序列，做包含处理后出现底分型 → 线段终结
- 区分第一种（特征序列有缺口）与第二种（无缺口，需反向确认）线段划分情形
- 未被终结的当前线段视为**未完成线段**，仅展示、不出信号

### 第 5 层：中枢

- 中枢由至少 3 个连续次级别走势（本级别计算中以笔为次级别）的价格重叠区间构成
- 中枢区间：ZG = min(各笔高点)，ZD = max(各笔低点)，需满足 ZG > ZD
- 中枢区间 [ZD, ZG]；中枢极值范围 [DD, GG]（所有构成笔的最低/最高点）
- 中枢扩展：后续次级别走势与 [ZD, ZG] 有重叠时，中枢延伸；离开中枢区间后中枢结束

### 第 6 层：背驰

- 采用「价格幅度 + MACD 面积」双重比较的主流量化口径：
  - 比较对象：离开最后中枢的走势段（c 段）与进入该中枢前的同向走势段（a 段）
  - 背驰成立条件（两条件须同时满足）：
    1. c 段价格变动幅度 < a 段价格变动幅度
    2. c 段对应 MACD 柱状图累计面积（绝对值）< a 段对应面积
- 趋势背驰：同向趋势中存在 ≥2 个中枢时，比较最后两个中枢间的离开段
- 盘整背驰：单中枢情形下，比较进入段与离开段
- MACD 参数固定使用标准参数（12, 26, 9）

### 第 7 层：一、二、三类买卖点

| 信号 | 定义（系统口径） | 确认时机 |
|------|------------------|----------|
| 一类买点 | 下跌趋势（≥2 个依次下移的中枢）中，离开最后中枢的向下段相对前一同向段发生趋势背驰，该段最低点 | 构成该买点的向下笔/线段完成并确认 |
| 一类卖点 | 对称：上涨趋势中离开最后中枢的向上段背驰，该段最高点 | 同上 |
| 二类买点 | 一类买点之后，第一次回调走势不创新低，该回调低点 | 回调笔/线段完成并确认 |
| 二类卖点 | 对称：一类卖点之后第一次反抽不创新高 | 同上 |
| 三类买点 | 次级别走势离开中枢后，回调不回到中枢区间 [ZD, ZG] 内，该回调低点 | 回调笔/线段完成并确认 |
| 三类卖点 | 对称：离开中枢后反抽不回到中枢区间内 | 同上 |

- 信号级别标注：必须标明产生信号的结构级别（笔级别 / 线段级别）与 K 线周期（daily / m30）
- 同一 K 线周期同一位置同一类型信号，通过唯一键去重，**只记录一次**

### 确认与不重绘策略

- 所有正式信号只在**收盘确认**后生成，盘中不产生任何正式信号
- 已确认信号写入数据库后**永不修改**
- 唯一例外：数据源发生数据修正（复权调整、补数）时，受影响信号标记为 `invalidated` 并保留原记录与失效原因，不允许静默删除
- 当前未完成结构（未完成笔/线段）可在 K 线图上以浅色虚线展示，但**不得产生信号、不得计入徽标**

## 用户故事 & 验收标准

### Story 1：自选股列表一眼看到信号状态

**作为** 散户
**我希望** 打开自选股列表时一眼看到每只股票的当前缠论信号状态
**从而** 快速识别哪些股票需要重点关注，不用逐一打开 K 线

**验收标准：**

- [ ] 自选股列表新增「信号」列，每行展示该股票**日线 + 30 分钟**的最新正式信号徽标：
  - 绿色 ▲：最近 3 根 K 线内出现买点（一/二/三类，徽标上标注 1/2/3）
  - 红色 ▼：最近 3 根 K 线内出现卖点（一/二/三类）
  - 灰色「—」：无近期信号
  - 灰色「不足」：数据不足无法计算
- [ ] 徽标旁显示信号确认时间（如「今日 14:00」「昨日」）
- [ ] 双周期并列展示（日线徽标 + 30 分钟徽标），各自独立
- [ ] 列表支持按信号状态筛选：全部 / 有买点 / 有卖点
- [ ] 交易时段内徽标随列表行情刷新自动更新（复用现有 30 秒批量行情机制）
- [ ] 每行提供监控开关（见 Story 5）

## 功能需求

### 核心功能

**功能 1：缠论计算引擎（纯领域逻辑）**
- 纯 Python 实现，位于 Domain 层，**不依赖任何框架与 IO**，保证可单元测试
- 输入：K 线序列（OHLCV + 时间）；输出：合并 K 线、分型、笔、线段、中枢、背驰标记、买卖点信号
- 实现严格按「缠论算法口径」章节执行，算法版本常量内嵌于代码并写入结果

**功能 2：30 分钟 K 线聚合**
- 从原始分钟数据聚合为 30 分钟 K 线，固定 8 根/交易日：9:30-10:00、10:00-10:30、10:30-11:00、11:00-11:30、13:00-13:30、13:30-14:00、14:00-14:30、14:30-15:00
- 聚合规则：open=首分钟 open，close=末分钟 close，high=max，low=min，volume/amount=求和
- 聚合 K 线以**区间结束时刻**为时间戳；前复权口径与日线一致
- 分钟数据缺失时，该股票 30 分钟周期标记「数据不足」，不猜测、不插值

**功能 3：定时计算任务（APScheduler）**
- 日线任务：每个交易日收盘数据同步完成后触发（依赖同步任务完成事件，兜底定时 15:40）
- 30 分钟任务：每个交易日 8 根 30 分钟 K 线收盘后依次触发（10:05 / 10:35 / 11:05 / 11:35 / 13:35 / 14:05 / 14:35 / 15:05，预留免费数据延迟）
- 非交易日不触发（交易日历判断）
- 并发控制：同时计算股票数 ≤10，单次任务最多 200 只，超出顺延
- 计算前先校验数据新鲜度：最新 K 线时间戳未更新则跳过该股票并在任务日志中记录

**功能 4：信号比对与落库**
- 每次计算后与库内已有信号按唯一键（股票 + 周期 + 信号类型 + 信号时间 + 算法版本）比对
- 仅新增的已确认信号写库；重复不写、不重绘
- 中间结构（笔/线段/中枢）以结构快照覆盖式保存，供 K 线渲染

**功能 5：查询 API 与缓存**
- 信号状态与结构数据经 Redis 缓存（TTL 10 分钟），写库时主动失效对应 Key
- 自选股列表批量查询信号（一次请求返回当前用户全部启用股票的双周期最新信号）

**功能 6：前端展示**
- 自选股信号徽标列（Story 1）
- K 线缠论结构图层：笔/线段折线 + 中枢矩形 + 买卖点 markPoint（ECharts custom series / markArea / markPoint）
- 缠论信号历史标签页（Story 3）
- 策略监控面板（Story 5）

## 技术约束

### 性能

- 单只股票日线计算 ≤2 秒（约 750 根 K 线），30 分钟计算 ≤1 秒
- 100 只自选股双周期全量计算 ≤120 秒（并发 ≤10）
- 信号查询 API ≤500ms（缓存命中）
- K 线缠论图层渲染不显著影响现有 K 线加载性能（叠加数据随 K 线接口异步加载）

### 安全与合规

- 所有接口注入用户身份，信号与监控配置**按用户隔离**
- 全部信号展示处附「规则参考信号，不构成投资建议」声明（徽标 Tooltip、K 线 Tooltip、信号历史页首）
- 系统不提供任何下单能力，文案禁止出现「应立即买入/卖出」类表述

### 集成

- **模块二（行情）**：读取 `t_stock_daily_quote`；30 分钟聚合依赖新增分钟数据存储（见依赖）；K 线组件开放缠论图层插槽；自选股表开放信号列
- **模块一（AI 分析）**：信号 → 个股深度分析的跳转预填（Story 6）
- **数据与工具**：策略监控面板挂载于「数据与工具」导航下
- **APScheduler / Redis / MySQL**：复用现有基础设施

### 技术栈

- 计算引擎：纯 Python（Domain 层，无框架依赖，全量单元测试覆盖）
- 定时任务：APScheduler（FastAPI 进程内）
- 缓存：Redis（信号状态与结构快照）
- 持久化：MySQL
- 前端：React + ECharts（custom series / markPoint / markArea）

## 数据模型

| 表 | 说明 |
|----|------|
| `t_stock_minute_quote` | 原始分钟 K 线数据（30 分钟聚合的输入；新增） |

| `t_strategy_run_log` | 计算任务日志：周期、触发时间、耗时、成功/失败数、失败明细 |

## 风险评估

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|----------|
| 缠论流派差异导致算法验收争议 | 高 | 高 | 本 PRD 固定唯一口径；黄金样本集先行；验收对照报告留档 |
| 免费数据源分钟数据缺失或限流 | 中 | 高 | 开发前先验证三数据源分钟数据可用性；缺失则该股票 30 分钟周期降级为「数据不足」，不影响日线 |
| 免费数据延迟导致 30 分钟信号滞后 | 高 | 中 | 触发时间预留 5 分钟延迟窗口；界面明示「数据可能延迟」；不承诺实时性 |
| 背驰判断依赖 MACD 口径不一致 | 中 | 中 | MACD 由后端统一计算（复用 `t_stock_indicator` 口径），算法内不重复实现 |
| 双周期 × 大量股票计算超时 | 中 | 中 | 并发 ≤10、单次上限 200 只；结构快照增量更新 |
| 数据源修正导致历史信号与 K 线不符 | 低 | 高 | 信号标记 invalidated 并留痕，前端明示，不静默删除 |

### 信号类型编码

| 编码 | 含义 | 徽标 |
|------|------|------|
| buy1 / sell1 | 一/二类买卖点之一类 | ▲1 / ▼1 |
| buy2 / sell2 | 二类 | ▲2 / ▼2 |
| buy3 / sell3 | 三类 | ▲3 / ▼3 |

### 术语表

- **分型**：3 根合并 K 线中间极值的顶/底形态
- **笔**：相邻顶底分型之间的走势单元
- **线段**：由至少 3 笔构成、以特征序列分型终结的走势单元
- **中枢**：至少 3 个次级别走势重叠区间 [ZD, ZG]
- **背驰**：离开段价格幅度与 MACD 面积同时小于比较段
- **黄金样本集**：人工标注的历史 K 线结构基准，用于算法单元测试与验收
