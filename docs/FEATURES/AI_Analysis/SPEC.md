## 功能概述

AI 驱动的事件分析工具，支持五种事件类型输入，流式生成结构化分析文章，保存后自动归档到行业知识库，支持全文搜索和三视图浏览。

## 核心能力

- 流式输出（SSE）实时显示分析结果
- 五种事件类型：地缘政治 / 政策法规 / 财报季报 / 产业链分析 / 其他
- 自动行业标签提取（申万分类）
- 知识库三视图：行业视图 / 时间线视图 / 股票视图
- 全文搜索、相似问题提醒
- 大事提醒与新用户引导
