## 功能概述

基于缠论策略的自选股监控模块，自动计算笔/线段/中枢，标注买卖点信号，支持实时报警通知。

## 核心能力

- 自选股管理（添加/删除/分组）
- 缠论核心要素计算：笔、线段、中枢
- 买卖点自动标注（一买/二买/三买 + 对应卖点）
- 信号报警（页面弹窗 + 可选邮件通知）
- 每日收盘后自动计算所有自选股信号
- 联动模块一展示相关历史分析
